# 📝 Todo List - Desafío

## Descripción

Aplicación web simple para gestionar una lista de tareas (Todo List), desarrollada con HTML, CSS y JavaScript.

Permite agregar tareas dinámicamente, eliminarlas y marcarlas como completadas. Además, muestra en tiempo real el total de tareas y cuántas han sido completadas.

Este proyecto fue desarrollado como parte de un desafío práctico para aplicar manipulación del DOM, manejo de arrays de objetos y eventos en JavaScript.
